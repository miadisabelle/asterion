2 · The four grounds

ceremony-session-observer

The witness-room

Next.js UI (3950/3949). Reads only REDIS_URL + SESSION_DATA_DIR — while carrying 24 dead credential keys copied from asterion. Hand-rolled session reader (3rd copy), unprefixed Redis link keys, re-links destroy the first-witness timestamp. Scans ~3,985 dirs per list; ignores the existing session_index.jsonl.

asterion

The factory surface

Next.js on Vercel; Postgres asterion.* schema — tensions, entities, relations, events, beats. Its entities.external_id/external_source seam is exactly where sessions would enter the graph — nothing populates it. relation_type is a free string inside a DB unique key.

hooks-core 0.5.0

The typed twin

22 canonical events, versioned envelope, sha256 idempotency keys, byte-parity file sinks, permission-with-evidence, plan provenance. Zero deps, tested — and no hook invokes it. The observer-interpreter role doc already specifies the ceremony-link contract the observer rebuilt differently.

hooks-gateway 0.1.0

The receipt door

POST /events → validate envelope → first-witness ledger (202 accepted / 200 duplicate, attempts counted, side-effects never re-run) → stream fan-out. Memory ledger only; Postgres + Redis/NATS remain SPEC. No process runs it; no sink posts to it.

3 · Adjusting the observer in relation to asterion

Six aspects, each under 55 words, as commissioned.

Environment: subtract to what the code reads

The observer's .env is asterion's Vercel pull plus two lines. Code reads exactly REDIS_URL and SESSION_DATA_DIR. Delete the other 24 keys — live Neon and Upstash credentials in an app that never opens them are pure exposure. Decide the duplicated REDIS_URL on purpose; today position decides it.

54 words

Namespace the keyspace, or inherit asterion's discipline

Observer, asterion, and the wheel share one Upstash database. Asterion prefixes everything (asterion:*); the wheel stamps ceremony:*; the observer writes bare keys. Adopt a prefix (observer:* or the wheel's own session-link helper) so three tenants stop sharing an unmarked commons.

43 words

Retire the duplicate readers — the promise already written

The observer's lib/sessions.ts and lib/redis.ts are line-for-line twins of medicine-wheel's session-reader and session-link. Its own KINSHIP.md records the extraction and promises the swap. Make the swap: two local forks become two imports, and every fix lands once.

40 words

Speak canonical events, not one agent's dialect

The observer hand-parses Claude's native hook names, so 364 MB of hermes events — and every codex, gemini, openclaw session — is invisible to it. Consuming hooks-core's NATIVE_EVENT_MAP + canonical names makes it the witness of every agent in the house, sorted by captured_at, not a field nobody stamps.

47 words

Give the link record provenance and first-witness honesty

Today's link is {ceremony_id, session_id, linked_at, notes} — and re-linking overwrites linked_at, destroying the first witness. Carry hooks-core's PlanProvenance fields (source session, trace id, cwd) and the ledger's first-received semantics: a relation you can replay, not a timestamp that lies.

40 words

Feed from the index, not the full scan

Every listing walks ~3,985 session directories; search walks them twice. _sessiondata/data/session_index.jsonl already exists, appended on every session start by the very pipeline the observer watches. Read the index, fall back to scan — the observer becomes instant on the data it already trusts.

7 · Forgewright's Graph — the seat named Session that no one was shown to

@forgewright/platform is the graph-based runtime with ceremony governance — and its Graph tab renders a hardcoded placeholder while a complete GraphView sits unreferenced in src/components/designer/graph/. The fourth room with a finished tool asleep on the bench.

  • The contract is the asset: a Zod-first graph schema — 10 node types including Session, 11 edge types, OCAP on every node and edge (sacred nodes render at 0.35 opacity — consent as visual law), KuzuDB with honest in-memory fallback.
  • Session is first-class and unborn: typed, colored (#38bdf8), scope-filtered (ScopeMode: 'session' is the default) — and nothing anywhere mints a Session node. ingestSession is one missing function. The chronicle client already carries sessionId across the wire and discards it at the UI boundary.
  • Presenting the Asterion graph there: forgewright has zero knowledge of asterion today. The minimal path: add a Tension node type (its Phase vocabulary is pre-agreed with ontology-core), adapt asterion's existing GET /api/graph shape, synthesize OCAP at the boundary — the one real impedance, because asterion carries no consent metadata at all.
  • It already reads the wheel honestly: MW_API_URL validated, counts refused when the wheel doesn't answer ("reporting 0 for 'we could not ask' is the same class of dishonesty as an empty array standing in for a failed fetch").
