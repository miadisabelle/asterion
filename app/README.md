# Asterion

**The factory's event-driven surface: structural tension charts and state machines rendered as routes.**

Asterion is part of Miadi — a relational software factory: film-media as knowledge practice, with the chronicle (`/srv/miadi/episodes/miadi-chronicle`) as its episodic memory system. Asterion is where the factory's structural tension becomes something a browser can walk: tensions, events, projects, threads, layers, and the graph that relates them.

## What lives here

| route | surface |
|---|---|
| `/tensions` | structural tension charts, event-driven |
| `/events` | the event stream the charts advance on |
| `/projects` · `/threads` · `/layers` | the relations a factory runs on |
| `/graph` | the whole, as one picture |
| `/docs` | the surface's own documentation |

## The wheel it carries

`diagrams/mino-steering-day.wheel.mmd` is the measured first draft of **MinoSteeringDay** (`miadi.mino`, via the stateloom MCP, exported 2026-08-03): 14 states and 24 events — the whole wheel of the ceremonial participation of Mino, the STC seat, with humans. Asterion's purpose is to make machines like this one — and the charts they steward — interactive.

## Lineage

- Born from a v0 draft (2026-05-14), grown inside `jgwill/Miadi` at `packages/asterion`.
- Becoming `miadisabelle/asterion` — the remote lives outside the `jgwill` handle because the coaiajs toolset relates GitHub **project fields** to **issues** within a handle's semantic, and asterion must relate to those projects rather than sit inside them.
- Deployed on Vercel as the project `asterion`.
